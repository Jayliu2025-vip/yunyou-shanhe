# 云游山河视觉改版 Implementation Plan

**Goal:** 按用户本轮要求提升全流程审美，以青绿山水旅行手册统一首页、准备、训练、弹窗、文牒及结算页。

**Architecture:** 保留既有 DOM 事件 ID 和训练控制。新增独立主题样式；首页及文牒使用已有授权风景素材，展示已有旅程状态。原循证方案中的医学行为调整继续作为后续事项。

**Tech Stack:** 原生 HTML / CSS / JavaScript / Canvas，既有零依赖本地服务器。
