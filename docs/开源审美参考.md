# 开源审美参考 —— 云游山河可用/已用的开源项目清单

> 目的：回答"审美方面有哪些类似的开源项目可以借鉴/引入"，并记录每一项的
> 许可、适用层级与本项目对应的取舍。所有仓库信息均已于 2026-09 经 GitHub API 核实。

## 一、总原则：借"规范与素材"，不整库引入组件

本项目通过小程序 **web-view 壳 + H5** 架构运行，且已经形成完整的
"宣纸 + 墨 + 朱砂印"自成一体的中国风视觉体系。整库引入通用 UI 框架
（WeUI/Vant 等）会带来两重冲突：

1. **风格冲突**：通用框架是灰白/蓝调的现代风，与水墨国风互相打架；
2. **架构冲突**：小程序 UI 框架面向原生页面，web-view 内用不上。

因此采取 **"借设计规范、借色彩体系、借开源素材"** 的方式，而非引入组件库。
若未来将游戏从 H5 迁移为**原生小程序**（如摄像头改用 `wx.createVKSession`），
下表第一组框架即可直接选用。

## 二、小程序 UI 框架（原生重写时选用；现 web-view 架构下作设计规范参考）

| 项目 | 许可 | Stars | 定位与可借鉴点 |
|---|---|---|---|
| [Tencent/weui](https://github.com/Tencent/weui) | 微信官方设计团队 | ★27.4k | **微信官方视觉语言**。web-view 内 H5 与微信原生 UI 共处一屏，表单、按钮按压态、Toast、对话框的交互尺度以 WeUI 为基准对齐，用户在微信内使用才"不觉突兀" |
| [Tencent/tdesign-miniprogram](https://github.com/Tencent/tdesign-miniprogram) | MIT | ★1.8k | 腾讯企业级设计体系 TDesign 的小程序实现；组件质量高、文档全，**原生重写首选** |
| [youzan/vant-weapp](https://github.com/youzan/vant-weapp) | MIT | ★18.4k | 组件数量最全、社区最活跃的有赞小程序组件库；表单/弹层/反馈类组件可直接对照其交互规范 |
| [weilanwl/ColorUI](https://github.com/weilanwl/coloruicss) | MIT | ★12.4k | 纯 CSS 类库，**色彩与渐变灵感库**；本项目描金/朱砂渐变的层次感可对照其配色思路微调 |

## 四、开源字体（✅ 已落地）

| 项目 | 许可 | 说明 |
|---|---|---|
| [lxgw/LxgwWenKai-Screen](https://github.com/lxgw/LxgwWenKai-Screen) | **SIL OFL 1.1** | 霞鹜文楷 GB 屏读版（基于 Fontworks Klee One）。**安卓/微信 WebView 没有 KaiTi**，原本楷体标题会退化成宋体，三端观感割裂；引入后 iOS/安卓/桌面统一楷体。OFL 附加条款明确允许"仅为 Web Font 投递子集化"，合规无忧 |

落地方式（v1.3.2）：
- `tools/build-font-subset.py`：从 H5 源码提取实际用字（1191 汉字 + 标点 + ASCII），
  用 fontTools 子集化为 326KB woff2（全量 24MB）；
- `css/style.css` `@font-face` + `--font-kai` 栈首位、`js/game.js` canvas 的 `FONT_KAI`
  同步（canvas 印章/景点字同样受益）；
- `sw.js` 预缓存该字体，**离线可用**；许可文件见 `assets/fonts/`。

其他可考虑的开源字体（按需）：[霞鹜文楷 Lite](https://github.com/lxgw/LxgwWenKai-Lite)（更小体积）、
[思源宋体/黑体](https://github.com/adobe-fonts/source-han-sans)（OFL-1.1，正文替代方案，当前系统字体栈已够用，不引入）。

## 五、其他值得关注的国风开源资源（调研结论：暂不引入，留档）

- **水墨/古画素材**：台北故宫 Open Data、[Getty Open Content](https://www.getty.edu/projects/open-content/) ——
  公版古画可用作结算页/文牒底纹；当前程序化水墨已够用且更轻量。
- **图标**（✅ v1.3.3 已落地 → [Lucide](https://github.com/lucide-icons/lucide)，ISC License）：
  全站 emoji 图标已替换为 Lucide 线性描边图标。选型对比：Iconfont 的"手绘中国风"
  图标集需逐个核对授权、不可批量合规；Lucide 为 ISC 许可、描边风格以
  `stroke: currentColor` 染色，可随墨色/朱砂/描金语境自动着色，43 枚以内联
  sprite 嵌入（零请求、离线可用，源文件存档 `vendor/lucide/`）。备选：
  [Tabler Icons](https://github.com/tabler/tabler-icons)（MIT，风格相近）、
  [Phosphor](https://github.com/phosphor-icons/core)（MIT，多字重）
- **动效参考**：[animista](https://animista.net/) / [cubic-bezier](https://cubic-bezier.com/) ——
  调参工具类，用于印章"盖印"、文牒钢印等动效的缓动曲线设计（本项目已手写实现）。

## 六、结论

| 需求 | 选型 |
|---|---|
| 三端统一楷体标题 | ✅ 霞鹜文楷 GB 屏读版子集（OFL-1.1，已落地） |
| 全站图标体系 | ✅ Lucide 线性描边图标内联 sprite（ISC，v1.3.3 已落地） |
| 色彩扩展 | 中国传统色色卡（zhongguose / chinese-colors，MIT） |
| web-view 内交互规范 | WeUI 官方设计语言（对齐按压态/表单尺度） |
| 未来原生小程序重写 | TDesign（腾讯系、MIT）或 Vant Weapp（MIT） |
| 纯 CSS 灵感 | ColorUI（MIT） |
