# 云游山河 · 心脏康复集章之旅

面向**冠心病 II/III 期（居家）康复**的体感游戏原型。患者面对普通摄像头**原地踏步、抬手摘印**，
在浏览器里"云游"中国十二景，为每处景点集齐印章、盖入通关文牒。

> ⚠️ 本项目为科研原型，**不能替代医嘱**。训练方案（强度、时长、频率）请遵康复医师指导。

---

## 一、快速开始

**方式一（推荐）**：双击 `启动游戏.bat`，浏览器自动打开 `http://localhost:8616`。

**方式二**：在项目目录执行任意静态服务器，例如：

```bash
python -m http.server 8616
# 或 npx http-server -p 8616
```

然后浏览器访问 `http://localhost:8616`。

**手机（居家康复主力设备）**：摄像头权限要求 **HTTPS**（或 localhost），因此手机使用需一次部署：

```bash
# 局域网 HTTPS（手机与本机同一 WiFi），示例：
npx http-server -S -C cert.pem -K key.pem -p 8443
# 然后手机浏览器访问 https://<电脑IP>:8443
```

证书可用 `mkcert` 生成（手机上安装其根证书后无警告）。课题落地时建议部署到学院/医院已备案的 HTTPS 域名下，手机扫码即用。

- 摄像头权限需要 **localhost 或 HTTPS**，直接双击 index.html（file:// 协议）无法使用摄像头；
- 建议使用 **Chrome / Edge**（安卓）或 **Safari 16.4+**（iOS）；微信内打开请点右上角"在浏览器中打开"；
- 玩家身后退 2~3 米，让**全身**入镜（肩、髋、脚踝都可见时识别最稳）；游戏内已做手机适配（横屏引导、屏幕常亮、演示模式触屏踏步按钮）；
- **演示模式**：准备页勾选"演示模式"后无需摄像头——`←`/`→` 键踏步、鼠标当手；手机上演示可点屏幕左下"踏步"按钮；再勾"自动行走"可全自动播放，适合学术展示与展台。

**快速体验**：URL 加参数 `http://localhost:8616/?quick=1`（热身 20s → 主运动 90s → 整理 20s），用于调试和流程演示。

## 二、游戏与康复方案的对应关系

| 康复要素 | 游戏内实现 |
|---|---|
| 中等强度有氧 | 原地踏步推进风景，节拍器+脚印引导目标步频（92→104 步/分，自适应 84~124） |
| 上肢关节活动 | 印章/吉物在肩上、胸前、腰侧、体侧不同高度出现，需抬臂伸展摘取 |
| 三段式课程 | 热身 5min → 主运动 15/20/30min（可选）→ 整理放松 4min（呼吸引导+康复小知识轮播） |
| 强度监控 | 目标心率 = Karvonen 储备心率法（40%~60%，Tanaka 最大心率）；蓝牙心率带实时显示，超上限 12 秒自动暂停休息 |
| RPE 自评 | 主运动每 5 分钟弹出自评（0~10 表情量表，目标 3~4"有点累～稍累"），**回答后自动调整步频**（≥5 降速 8 步/分；**≥6"很累/不适"直接进入呼吸休息界面**，恢复后由患者决定继续或结束）；HUD 常驻"有点累？告诉教练"按钮 |
| β受体阻滞剂 | 准备页勾选后，**不做心率自动暂停**（心率仍实时显示并变色提示、超限事件写入记录），强度以 RPE 为主控（写入记录） |
| 坐姿模式 | 物件不再出现在低位，踏步可改为坐姿抬膝/摆臂（腿部出镜时自动切换摆臂计数） |
| 依从性设计 | 通关文牒集章（12 景 × 12 印 = 144 枚，环游一圈）、连续打卡、徽章墙、合拍奖励金印 |
| 场景区分 | 准备页可选**居家康复 / 院内监护**两版：院内版强度上限更保守（50% 储备心率）、心率超限 8 秒即暂停、RPE 每 3 分钟询问（便于医护观察），并写入训练记录的"场景"字段 |

## 三、心率数据接入（三种方式）

1. **蓝牙心率带**：标准心率服务 0x180D，兼容 Polar H7/H9/H10、迪卡侬、华为等（需 Chrome/Edge，HTTPS 或 localhost）；
2. **研究设备（津发科技手环等）**：准备页"研究设备"栏填入采集软件的 WebSocket 地址即可。游戏以 JSON 消息接收心率，字段名 `bpm` / `hr` / `heart_rate` 均可识别——津发设备的采集软件可经其 SDK/导出接口写一个几行的转发小程序（或由实验室网络中间件转发）将数据推送为 `{"bpm": 92}` 格式；
3. **手动输入**：运动前后指测脉搏填入，安全控制自动切换为以 RPE 为主。

## 五、调参（js/config.js）

研究人员常改的参数都集中在 `js/config.js`，改完刷新页面即生效：

```js
medical: {
  intensityLow: 0.40,   // 储备心率下限
  intensityHigh: 0.60,  // 储备心率上限
  rpeTargetLow: 3, rpeTargetHigh: 4,   // CR10 目标区间
  rpePromptIntervalSec: 300,           // RPE 弹窗间隔
  hrOverLimitPauseSec: 12,             // 心率超限自动暂停阈值
},
session: { warmupSec: 300, mainSec: 1200, cooldownSec: 240 },
tempo:  { start: 104, min: 84, max: 124, rpeHighAdjust: -8, rpeLowAdjust: 5 },
game:   { stampCardNeed: 12, itemRadius: 0.085, ... }
```

设置页"科研参数"也提供运行时可调的强度/步频/RPE 间隔（保存在 localStorage）。

## 六、技术架构

```
index.html            单页应用（主页/准备/游戏/结算/通关文牒/设置）
css/style.css         暖纸+墨色+印章红适老化大字界面，含手机适配（横屏引导/大按钮/精简HUD）
js/config.js          ★ 医学与游戏参数（科研调参入口，含院内/居家两套安全策略）
js/main.js            屏幕流转与事件接线（场景介绍卡/院内模式/WS心率/手机常亮）
js/game.js            游戏引擎：三段课程/节拍引导/物件与捕捉/自适应强度/安全暂停/康复小知识
js/pose.js            MediaPipe 姿态识别：踏步检测（踝-髋归一化+自适应基线）、
                      摆臂后备、演示输入；普通摄像头即可，无需 Kinect
js/scenes.js          十二景实景照片渲染（Ken Burns 缓动+道路合成层，缺图自动回退程序化水墨场景）
                      + 景点介绍文案 + 康复小知识文案
js/audio.js           WebAudio 合成音效 + 中文语音教练（零素材依赖）
js/hr.js              心率接入三通道：Web Bluetooth（0x180D）/ WebSocket 研究设备 / 手动输入
js/storage.js         localStorage 记录、打卡/徽章、CSV/JSON 导出
assets/photos/        12 景实景照片（约2.3MB，来源与许可见 CREDITS.md）
vendor/               MediaPipe 模型与 WASM（本地化，**完全离线运行，无需外网**）
```

姿态识别：MediaPipe Pose Landmarker（lite，33 关键点），GPU 推理失败自动降级 CPU。
踏步判定：踝-髋垂直距离按躯干长度归一化（抗远近变化）+ 站立基线自适应 + 滞回去抖。

## 七、移植到微信小程序的说明

当前为 H5 实现。若课题需要微信小程序形态：

1. **摄像头与骨骼**：小程序无法直接跑 TensorFlow.js/MediaPipe，可用微信自带
   `wx.createVKSession({ track: { body: { mode: 2 } } })`（VisionKit 人体检测，同样输出 33 关键点，
   坐标语义与 MediaPipe 接近），`js/pose.js` 的检测算法（归一化、基线自适应、滞回）可整体复用；
2. **游戏渲染**：Canvas 2D 绘制逻辑（`game.js`/`scenes.js`）可几乎原样迁入小程序 canvas；
3. **心率带**：微信蓝牙 API（`wx.openBluetoothAdapter` + 心率服务 0x180D）替换 `hr.js`；
4. 或者最省事的路径：小程序用 `web-view` 组件直接嵌本 H5（域名需 HTTPS 备案）。

## 八、安全设计要点（给伦理/方案撰写参考）

- 开始前强制安全确认（胸闷/胸痛/气短/头晕/心悸即停）；
- 心率超上限持续 12 秒（院内 8 秒）→ 自动暂停 + 呼吸引导休息界面，手动恢复；自动暂停累计 3 次后休息界面会建议结束训练；
- 全程"⏹ 停止"按钮置顶；结束方式（完成/主动/安全）写入记录；
- 无憋气发力设计：摘取动作为匀速抬臂，无 Valsalva 诱因；坐姿模式全程可坐；
- RPE 超标自动降频（-8 步/分），RPE ≥6 保守处置直接休息，避免"游戏激励"导致的强度过冲；
- β受体阻滞剂用户：心率自动暂停关闭（防药物性心率钝化导致误判），改以 RPE 与症状为主。
