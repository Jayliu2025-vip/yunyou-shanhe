# 云游山河 · 心脏康复集章之旅

面向**冠心病 II/III 期（居家）康复**的体感游戏原型。患者面对普通摄像头**原地踏步、抬手摘印**，
在浏览器里"云游"中国十三景，为每处景点集齐印章、盖入通关文牒；可选开启**力量小站**，
在主运动中插入间歇坐站练习（下肢力量与功能训练）。

> ⚠️ 本项目为科研原型，**不能替代医嘱**。训练方案（强度、时长、频率）请遵康复医师指导。

---

## 一、快速开始

**方式一（推荐）**：双击 `启动游戏.bat`，浏览器自动打开 `http://localhost:8616`。

**方式二**：在项目目录执行任意静态服务器，例如：

```bash
python -m http.server 8616
# 或 npx http-server -p 8616
```

然后浏览器访问 `http://localhost:8616`。

**手机（居家康复主力设备）**：摄像头权限要求 **HTTPS**（或 localhost），因此手机使用需一次部署：

```bash
# 局域网 HTTPS（手机与本机同一 WiFi），示例：
npx http-server -S -C cert.pem -K key.pem -p 8443
# 然后手机浏览器访问 https://<电脑IP>:8443
```

证书可用 `mkcert` 生成（手机上安装其根证书后无警告）。课题落地时建议部署到学院/医院已备案的 HTTPS 域名下，手机扫码即用。

- 摄像头权限需要 **localhost 或 HTTPS**，直接双击 index.html（file:// 协议）无法使用摄像头；
- 建议使用 **Chrome / Edge**（安卓）或 **Safari 16.4+**（iOS）；
- **微信内打开**会自动弹出引导（微信浏览器无法授权摄像头）：点右上角「···」→「在浏览器中打开」，
  或选"先体验"直接进入演示模式（无需摄像头）；URL 加 `?wechat=1` 可预览该引导层；
- 玩家身后退 2~3 米，让**全身**入镜（肩、髋、脚踝都可见时识别最稳）；游戏内已做手机适配（横屏引导、屏幕常亮、演示模式触屏踏步按钮）；
- **PWA/离线**：HTTPS 部署后浏览器菜单"添加到主屏幕"可全屏横屏启动（manifest + 印章风图标）；Service Worker 缓存静态资源与模型，**断网也能完整训练**——更新代码后首次联网访问会自动刷新缓存（版本号见 `sw.js`）；
- **演示模式**：准备页勾选"演示模式"后无需摄像头——`←`/`→` 键踏步、`↑` 键起坐、鼠标当手；手机上演示可点屏幕左下"踏步"按钮；再勾"自动行走"可全自动播放，适合学术展示与展台。

**快速体验**：URL 加参数 `http://localhost:8616/?quick=1`（热身 20s → 主运动 90s → 整理 20s），用于调试和流程演示。

## 二、游戏与康复方案的对应关系

| 康复要素 | 游戏内实现 |
|---|---|
| 中等强度有氧 | 原地踏步推进风景，节拍器+脚印引导目标步频（92→104 步/分，自适应 84~124） |
| 上肢关节活动 | 印章/吉物在肩上、胸前、腰侧、体侧不同高度出现，需抬臂伸展摘取 |
| 下肢力量（可选） | **力量小站**：主运动中每 4 分钟插入 75 秒间歇坐站（Otago 慢速口径，15 次/分节拍），每 3 次起坐发一枚印章；**默认关闭**，准备页勾选开启，需一把稳固靠墙无轮的椅子；膝角视觉检测起坐次数（髋-膝-踝，踝不可见时退化为髋-膝高度比） |
| 三段式课程 | 热身 5min → 主运动 15/20/30min（可选）→ 整理放松 4min（呼吸引导+康复小知识轮播） |
| 强度监控 | 目标心率 = Karvonen 储备心率法（40%~60%，Tanaka 最大心率）；蓝牙心率带实时显示，超上限 12 秒自动暂停休息 |
| **无设备安全模式** | **不连接心率设备也可安全训练**（2026 ESC 心脏康复指南认可居家/远程康复为有效替代）：RPE 主控 + 说话测试 + 症状监护，RPE 询问间隔收紧至 3 分钟；监护方式写入训练记录 |
| RPE 自评 | 主运动每 5 分钟弹出自评（0~10 表情量表，目标 3~4"有点累～稍累"），**回答后自动调整步频**（≥5 降速 8 步/分；**≥6"很累/不适"直接进入呼吸休息界面**，恢复后由患者决定继续或结束）；HUD 常驻"有点累？告诉教练"按钮 |
| β受体阻滞剂 | 准备页勾选后，**不做心率自动暂停**（心率仍实时显示并变色提示、超限事件写入记录），强度以 RPE 为主控（写入记录） |
| 坐姿模式 | 物件不再出现在低位，踏步可改为坐姿抬膝/摆臂（腿部出镜时自动切换摆臂计数） |
| 依从性设计 | 通关文牒集章（13 景 × 12 印 = 156 枚，环游一圈）、连续打卡、徽章墙、合拍奖励金印 |
| 趣味反馈 | 摘取连击变调音、步数/里程里程碑播报、末印预告（金框+专属音）、结算称号（山河行者等）——**只奖励协调与出勤，不激励强度** |
| 声音个性化 | 语音教练可选**男声/女声**（设置页按设备已装中文语音分组选择，可试听）；音效含 CC0 真实感素材（Kenney，泡泡/弹拨/确认音），缺素材自动回退合成音 |
| 背景轮换 | 同一景点内每 15 秒在本站**多张实拍图**（每站 4 张）之间 2 秒缓变淡切，画面常新但不跨地区——当前站语义始终清晰；可在 config.scene.photoRotateSec 关闭 |
| 能量估算 | kcal 按准备页"体重"输入折算（kcal = 步数 × 体重 × 0.00064，默认 70kg；粗估仅供参考，不用于处方） |
| 场景区分 | 准备页可选**居家康复 / 院内监护**两版：院内版强度上限更保守（50% 储备心率）、心率超限 8 秒即暂停、RPE 每 3 分钟询问（便于医护观察），并写入训练记录的"场景"字段 |

## 三、心率数据接入（三种方式，可不接）

> **不连接任何设备也可以安全训练**。2026 ESC 心脏康复指南将居家康复/远程康复定为"有效替代方案"，
> 《中国心血管疾病患者居家康复专家共识》对低强度居家运动（40%~60% 储备心率 ≈ Borg 11~13）有明确推荐。
> 未连接设备时游戏自动进入**无设备安全模式**：以 RPE 疲劳自评（每 3 分钟询问）+ 说话测试
> （能连贯说话但唱不了歌 = 强度合适）+ 症状自我监护为主控，开场语音播报安全口诀；
> 训练记录的"监护方式"字段会区分 心率设备 / 手动脉搏 / 无设备(RPE主控)，便于分组分析。

1. **蓝牙心率带**：标准心率服务 0x180D，兼容 Polar H7/H9/H10、迪卡侬、华为等（需 Chrome/Edge，HTTPS 或 localhost）；
2. **研究设备（津发科技手环等）**：准备页"研究设备"栏填入采集软件的 WebSocket 地址即可。游戏以 JSON 消息接收心率，字段名 `bpm` / `hr` / `heart_rate` 均可识别——津发设备的采集软件可经其 SDK/导出接口写一个几行的转发小程序（或由实验室网络中间件转发）将数据推送为 `{"bpm": 92}` 格式；
3. **手动输入**：运动前后指测脉搏填入，安全控制自动切换为以 RPE 为主。

## 五、调参（js/config.js）

研究人员常改的参数都集中在 `js/config.js`，改完刷新页面即生效：

```js
medical: {
  intensityLow: 0.40,   // 储备心率下限
  intensityHigh: 0.60,  // 储备心率上限
  rpeTargetLow: 3, rpeTargetHigh: 4,   // CR10 目标区间
  rpePromptIntervalSec: 300,           // RPE 弹窗间隔
  hrOverLimitPauseSec: 12,             // 心率超限自动暂停阈值
},
session: { warmupSec: 300, mainSec: 1200, cooldownSec: 240 },
tempo:  { start: 104, min: 84, max: 124, rpeHighAdjust: -8, rpeLowAdjust: 5 },
game:   { stampCardNeed: 12, itemRadius: 0.085, ... }
exercise: { blockEverySec: 240, blockDurSec: 75, blockTempo: 15, repsPerStamp: 3, ... }  // 力量小站
```

设置页"科研参数"也提供运行时可调的强度/步频/RPE 间隔（保存在 localStorage）。

## 六、技术架构

```
index.html            单页应用（主页/准备/游戏/结算/通关文牒/设置）
css/style.css         暖纸+墨色+印章红适老化大字界面，含手机适配（横屏引导/大按钮/精简HUD）
js/config.js          ★ 医学与游戏参数（科研调参入口，含院内/居家两套安全策略）
js/main.js            屏幕流转与事件接线（场景介绍卡/院内模式/WS心率/手机常亮）
js/game.js            游戏引擎：三段课程/节拍引导/物件与捕捉/自适应强度/安全暂停/康复小知识
                      /力量小站（间歇坐站状态机：预告→坐站→收尾，RPE≥5 自动跳过下一站）
js/pose.js            MediaPipe 姿态识别：踏步检测（踝-髋归一化+自适应基线）、摆臂后备、
                      坐站检测（膝角滞回，踝不可见时退化判定）、演示输入；普通摄像头即可，无需 Kinect
js/scenes.js          十三景实景照片渲染（Ken Burns 缓动+道路合成层，缺图自动回退程序化水墨场景）
                      + 景点介绍文案 + 康复小知识文案
js/audio.js           WebAudio 合成音效 + 中文语音教练（零素材依赖）
js/hr.js              心率接入三通道：Web Bluetooth（0x180D）/ WebSocket 研究设备 / 手动输入
js/storage.js         localStorage 记录、打卡/徽章、CSV/JSON 导出
assets/photos/        13 景实景照片 ×4 张/站（约 8.7MB，16:9、每张 ≤210KB；来源与许可见 CREDITS.md）
assets/fonts/         霞鹜文楷 GB 屏读版 webfont 子集（326KB，OFL-1.1，三端统一楷体；见 CREDITS.md）
manifest.json/sw.js   PWA：主屏图标与离线缓存（页面网络优先、静态资源缓存优先+后台更新；版本号失效）
vendor/               MediaPipe 模型与 WASM（本地化，**完全离线运行，无需外网**；Apache 2.0，见 vendor/CREDITS.md 与 vendor/LICENSE）
miniprogram/          微信小程序 web-view 壳（可直接导入微信开发者工具，见下节）
```

实景照片**按需加载**：首屏只拉当前站与下一站（约 400KB），换站时预取下一站，缺图自动回退程序化水墨场景。

姿态识别：MediaPipe Pose Landmarker（lite，33 关键点），GPU 推理失败自动降级 CPU。
踏步判定：踝-髋垂直距离按躯干长度归一化（抗远近变化）+ 站立基线自适应 + 滞回去抖。

## 七、接入微信小程序（web-view 壳，已备好）

仓库内 `miniprogram/` 是可直接导入微信开发者工具的小程序壳（web-view 加载已部署的 H5）。步骤：

1. **部署 H5 到 HTTPS 备案域名**：如 `https://rehab.example.edu.cn/yunyou/`（医院/学院已备案域名最佳）；
2. **配置业务域名**：微信公众平台（mp.weixin.qq.com）→ 开发管理 → 开发设置 → 业务域名，
   添加上述域名，并按提示把校验文件放到网站根目录；
3. **改壳里的地址**：`miniprogram/pages/index/index.js` 顶部 `H5_URL` 替换为部署地址
   （替换后壳会自动隐藏"未配置"提示页）；
4. **导入开发者工具**：微信开发者工具导入 `miniprogram/` 目录，
   把 `project.config.json` 的 `appid` 换成你们的小程序 appid（现为占位 `touristappid`）。

**前置条件与注意**：
- web-view 组件要求**企业主体**小程序（个人主体不可用）——需尽早确认主体资质；
- 微信 web-view 内 `getUserMedia`（摄像头）在 iOS/部分安卓版本受限：H5 已内置
  微信内引导层与演示模式降级；**患者正式使用前务必真机实测**摄像头可用性，
  若不可用则走原生迁移路径（`wx.createVKSession({ track: { body: { mode: 2 } } })`
  人体检测，同样输出 33 关键点，`js/pose.js` 的检测算法可整体复用，
  `game.js`/`scenes.js` 的 Canvas 2D 绘制可近乎原样迁入小程序 canvas）；
- 心率带：原生路径可换 `wx.openBluetoothAdapter` + 心率服务 0x180D 替换 `hr.js`。

## 八、安全设计要点（给伦理/方案撰写参考）

**医学依据**（2026-09 复核）：2026 ESC 心脏康复指南（Eur Heart J, doi:10.1093/eurheartj/ehag099，
居家/远程康复为有效替代、数字工具被推荐）；《中国心血管疾病患者居家康复专家共识》(2022)
（低强度 40%~60% HRR ≈ Borg 11~13）；Stefanakis 2022 系统综述（居家康复严重不良事件
≈1/23,823 患者·时）；CSANZ 2023（无监护运动自监 RPE + 说话测试 + 症状）。
**力量小站依据**（2026-09 增补）：《中国人群身体活动指南（2021）》65岁+每周至少 3 天
大肌群力量与健骨练习；WHO《身体活动与久坐行为指南（2020）》老年人多成分活动强调功能性
力量（≥3天/周）；《World guidelines for falls prevention and management for older adults》
（Montero-Odasso 2022, Age and Ageing 51(9)）——渐进抗阻力量训练为运动干预核心成分；
Otago 运动方案（坐站 4次×2组起步、慢速、可扶椅）。

- 开始前强制安全确认（胸闷/胸痛/气短/头晕/心悸即停）；
- **无设备安全模式**：未连接心率设备时 RPE 主控（间隔 3 分钟）+ 说话测试 + 症状监护，
  开场语音告知；心率超限自动暂停仅在**实时心率数据流**下启用；
- 心率超上限持续 12 秒（院内 8 秒）→ 自动暂停 + 呼吸引导休息界面，手动恢复；自动暂停累计 3 次后休息界面会建议结束训练；
- 全程"⏹ 停止"按钮置顶；结束方式（完成/主动/安全）写入记录；
- 无憋气发力设计：摘取动作为匀速抬臂，无 Valsalva 诱因；坐姿模式全程可坐；力量小站明确口播"慢起慢坐、不憋气"；
- **力量小站安全闸门**（默认关闭，勾选开启）：开启时语音提示"稳固、靠墙、无轮子的椅子"；
  小站节拍固定 15 次/分慢速（起坐量被时长封顶，游戏不奖励"快和猛"）；不计入步频合拍奖励、
  不改变有氧步频处方、小站期间里程暂停；HUD 常驻"跳过小站"按钮（语音引导"不舒服就跳过"）；
  **RPE ≥5 自动跳过下一个小站**，≥6 仍走保守休息流程；膝部不可见时温和提醒且不计数、不惩罚；
- RPE 超标自动降频（-8 步/分），RPE ≥6 保守处置直接休息，避免"游戏激励"导致的强度过冲；
- β受体阻滞剂用户：心率自动暂停关闭（防药物性心率钝化导致误判），改以 RPE 与症状为主。
