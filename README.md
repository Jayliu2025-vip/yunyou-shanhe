# 云游山河 · 心脏康复集章之旅

当前版本 **v1.4.0**。手机优先的H5研究原型，保留十三景纪念章、动作识别和旅程反馈。

## 当前能做什么

- **演示体验**：可选模拟动作或摄像头体验；记录始终进入演示分区。
- **正式训练入口**：检查可信、有效且可执行的康复计划。当前仓库没有医院计划服务，入口会明确阻断，不用年龄公式或用户勾选伪造医生签发。
- **停止与恢复**：不适停止不可恢复；普通暂停需重新确认症状、疲劳和必要输入；页面隐藏、动作失效、设备数据失效会暂停。
- **记录**：演示、正式及旧版数据分开。结果和旅程进度一起保存；写入失败显示错误并可重试；停止/中断标记跨刷新保留。
- **可穿戴基础**：标准BLE心率、研究WebSocket及手动脉搏分别处理；提供连接代次、接触质量、时间戳和数据过期检查。尚未验证具体设备型号。

本原型的演示参数不构成运动处方，软件测试不能证明临床安全或疗效。真实使用仍需临床团队与设备/微信真机验证。

## 本地运行

```powershell
node server.js --port 8618 --host 127.0.0.1
```

- 游戏：`http://127.0.0.1:8618/`
- 快速演示：`http://127.0.0.1:8618/?quick=1`
- 可切换尺寸的预览：`http://127.0.0.1:8618/visual-preview.html?quick=1`
- 美术素材：`http://127.0.0.1:8618/docs/emblem-preview.html`

快速演示约为20秒热身、90秒主段、20秒整理，不属于患者训练方案。实际手机摄像头需要受支持的安全上下文和权限，微信web-view兼容性需实测。

## 怎样体验新版

1. 首页选择“演示体验记录”，进入出发准备。
2. 逐项完成当前状态与环境确认。仅测试时选择模拟动作，可开启自动播放。
3. 训练中可暂停；恢复前完成检查。选择轻松不会自动加速。
4. 使用“不舒服，立即停止”会锁定本次会话，所有恢复入口失效。
5. 正常结束需补充结束后状态，并离开复核页才能完成会话。若刷新/中断，保留未确认标记。
6. 演示测试可在首页显式重置演示停止状态，历史记录不会因此删除。正式训练的停止状态不提供患者自行清除入口。

## 数据与接入边界

- v2存储按 `demo` / `clinical` 分区；旧 `yysn_*` 数据不改写、不推定为正式训练，可在设置页单独导出。
- 新记录不保存原始视频、任意设备载荷或姓名。当前仅本地保存，未实现医院上传或“已同步”回执。
- `js/rehab-plan.js` 的 PlanGateway 需要宿主提供真实的 `fetchPlan` 与 `verifyPlan`；默认不请求任何医院服务。URL参数、粘贴JSON、手动勾选不能形成可信计划。
- 当前正式执行器只支持基本踏步，拒绝正式力量处方和无法解释的量表。更多动作、医生复核及上传流程属于下一阶段。
- 研究网关仅支持WSS或本机WS。没有具体品牌/协议/实物前，不宣称兼容任意手表或手环。

详见 [接入契约](docs/2026-09-16-计划设备与结果契约.md) 和 [本轮验证](docs/2026-09-16-安全基础验证.md)。历史设计保存在docs；旧说明快照在docs/archive，不作为当前功能或临床依据。

## 主要文件

| 文件 | 职责 |
|---|---|
| js/rehab-plan.js | 计划结构、来源验证边界与演示计划 |
| js/session-safety.js | 会话安全状态与计时异常 |
| js/hr.js | 心率连接、样本质量、断连与过期 |
| js/storage.js | 数据分区、持久标记、结果与最小摘要 |
| js/game.js / js/main.js | 游戏执行与界面控制 |
| js/art.js / assets/art | 已选B方案的纪念章及道具 |
| css/theme.css | 与小喜鹊协调的青绿界面 |

Service Worker缓存版本随发布更新；修改前端后需要更新sw.js并检查刷新后的真实版本。
